# Inbox line format

One line per ask, any order, in `<root>/inbox.md`:

`[YYYY-MM-DD] [email | chat | DM | meeting] [name and org, or "internal"] the ask in one line → sources/YYYY-MM-DD-<slug>.md`

The original (email text pasted, chat export, meeting note) is saved to `<root>/sources/YYYY-MM-DD-<slug>.md`. The inbox line links to it. Neither is dropped. A dropped material's inbox line links to its library index row instead; the file itself lives in the library, never in sources/.
